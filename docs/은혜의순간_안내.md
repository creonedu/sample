# 들벗교회 「은혜의 순간」 안내

일상의 순간을 사진으로 담아 **모네 풍 그림**으로 바꾸고, **감사일기**를 쓰면 어울리는 **성경 말씀**을 추천해 한 장의 카드로 저장·공유하는 앱입니다.

- 주소: `https://<배포 도메인>/grace/`
- 흐름: 사진 찍기 → 모네 풍 그림 → 감사일기 → 말씀 추천(3구절 중 선택) → 카드 저장 · 공유

## 앱처럼 설치하기
- **아이폰(사파리)**: 공유 버튼 → "홈 화면에 추가"
- **안드로이드(크롬)**: 메뉴 ⋮ → "앱 설치" 또는 "홈 화면에 추가"

## 특징
- **서버·AI 비용 없음**: 그림 변환은 휴대폰 안에서 처리합니다(사진이 외부로 전송되지 않음).
- **개인정보**: 사진과 일기는 그 휴대폰에만 저장됩니다. 앱 데이터를 지우거나 기기를 바꾸면 기록이 사라지니, 소중한 카드는 "이미지 저장"으로 사진첩에 보관하세요.
- **공유**: "공유하기"를 누르면 휴대폰 공유 창이 열려 카카오톡·인스타그램 등으로 바로 보낼 수 있습니다.
- 카드에 일기를 넣지 않고 그림과 말씀만 공유할 수도 있습니다("카드에 감사일기 함께 담기" 해제).

## 말씀 데이터 바꾸기
- `grace/verses.js` 에 주제별(감사, 자연과 창조, 가족과 사랑, 친구와 공동체, 일용할 양식, 평안과 쉼, 위로와 회복, 일과 배움, 기쁨과 축하, 예배와 은혜, 오늘 하루) 말씀과 연결 단어가 있습니다.
- 본문은 저작권이 만료된 **개역한글**입니다. **개역개정**을 쓰려면 대한성서공회 사용 허락을 받은 뒤 `text` 만 바꾸세요.
- 구절·단어를 추가하면 바로 추천에 반영됩니다.

## 다음 단계로 고려할 것
- 교회 공동체 피드(성도들이 올린 은혜의 순간을 함께 보기): 로그인과 저장 서버(예: Supabase, Firebase)가 필요합니다.
- AI 기반 그림 변환(더 사실적인 모네 화풍): 이미지 생성 API 비용이 발생합니다.
- 앱스토어/플레이스토어 출시: 지금 웹앱을 Capacitor 등으로 감싸 출시할 수 있습니다.
