# PRD — 크레온에듀 교재 구매 페이지 (교재몰 v1)

| 항목 | 내용 |
|---|---|
| 문서 버전 | v1.0 (2026-10-03) |
| 오너 | 크레온에듀(주) 대표이사 |
| 상태 | 초안 → 테스트 결제 가능 상태로 구현 완료, 실결제 오픈 준비 중 |

---

## 1. 배경과 문제

- 현재 교재 구매는 학원 데스크 현금/카드 결제, 계좌이체, 문자 안내 등으로 흩어져 있어
  **수납 확인·누락·재고 파악에 운영 시간이 많이 듭니다.**
- 학부모는 학원에 들르거나 이체 후 문자로 알려야 하는 등 **구매 과정이 번거롭습니다.**
- 교재 대금이 수강료와 섞여 **매출 집계가 어렵습니다.**

## 2. 목표

| 목표 | 측정 지표 (오픈 3개월 후) |
|---|---|
| 학부모가 휴대폰으로 3분 안에 교재를 구매 | 결제 완료율(주문 시작 대비) 70% 이상 |
| 교재 수납 업무 자동화 | 데스크 교재 수납 건수 80% 감소 |
| 주문 누락 0건 | 결제 완료 건 = 시트 기록 건 일치율 100% |

### 하지 않는 것 (v1 범위 밖)
- 회원가입/로그인, 포인트·쿠폰, 정기구독
- 재고 수량 자동 차감 (v1은 '품절' 수동 표시)
- 관리자 전용 화면 (v1은 구글 시트 + 토스 상점관리자로 운영)
- 온라인 부분 취소/환불 자동화 (토스 상점관리자에서 처리)

## 3. 사용자

| 사용자 | 주요 니즈 |
|---|---|
| **학부모 (주 구매자)** | 우리 아이 레벨 교재를 정확히, 빨리 결제. 카카오페이·토스페이 등 간편결제. 대부분 **모바일** |
| **학원 데스크/담임** | 누가 무엇을 샀는지 반별로 확인 후 수업 시간에 전달 |
| **본사 운영팀/대표** | 매출 확인, 교재·가격 수정, 환불 처리 |

## 4. 사용자 흐름

```
교재 목록 → (분류 선택) → [담기] → 장바구니(수량 조절)
   → 주문/결제: 주문자·학생 정보 입력 → 받는 방법(학원 수령 / 택배) 선택
   → 결제수단 선택(토스 결제위젯) → 약관 동의 → [결제하기]
   → 토스 결제창 → 결제 완료 페이지(주문번호·영수증)
   → (자동) 서버가 결제 승인 + 구글 시트에 주문 기록
```

## 5. 기능 요구사항

### 5.1 교재 목록
- [x] 분류 탭: 전체 / ESL 정규 / TOEFL / 문법·어휘 / 방학 특강 (설정 파일에서 수정)
- [x] 교재 카드: 표지(사진 또는 자동 생성 표지), 분류·레벨, 이름, 설명, 가격, [담기]
- [x] 품절 표시 및 구매 차단

### 5.2 장바구니
- [x] 수량 +/−, 삭제, 소계, 무료배송까지 남은 금액 안내
- [x] 브라우저에 저장되어 새로고침해도 유지

### 5.3 주문/결제
- [x] 필수 입력: 주문자 이름, 휴대폰, 학생 이름 / 선택: 이메일, 캠퍼스·반
- [x] 받는 방법: **학원 수령(무료)** / **택배**(기본 3,000원, 50,000원 이상 무료 — 설정 가능)
- [x] 택배 선택 시 주소 검색(다음 우편번호 서비스)
- [x] 결제수단: 토스페이먼츠 결제위젯 (카드, 계좌이체, 가상계좌, 휴대폰, 토스페이·카카오페이·네이버페이 등 — 계약에 따라 노출)
- [x] 이용약관·개인정보 수집·환불정책 동의 필수
- [x] 입력 오류 시 해당 칸 빨간 표시 + 안내

### 5.4 결제 승인 (서버)
- [x] **가격은 서버에서 다시 계산** — 브라우저 금액 조작 시 승인 거부
- [x] 품절·없는 교재·비정상 수량 거부
- [x] 토스페이먼츠 승인 API 호출 (중복 승인 방지 키 사용)
- [x] 승인 완료 시 구글 시트로 주문 기록 전송 (선택 설정)

### 5.5 결과 페이지
- [x] 성공: 주문번호, 교재, 금액, 결제수단, 받는 방법, 영수증 링크
- [x] 실패/취소: 사유, 주문번호, 고객센터, 다시 결제 버튼

### 5.6 법적 필수 표시 (전자상거래법)
- [x] 하단: 상호, 대표자, 사업자등록번호, 통신판매업 신고번호, 주소, 연락처, 개인정보보호책임자
- [x] 이용약관 / 개인정보처리방침 / 교환·환불 정책 (현재 예시 문구 → **오픈 전 교체 필요**)

## 6. 비기능 요구사항

| 항목 | 기준 |
|---|---|
| 모바일 | 360px 폭 휴대폰에서 가로 스크롤 없이 사용 |
| 속도 | 첫 화면 2초 이내 (빌드 도구 없는 정적 페이지) |
| 보안 | 시크릿 키는 서버 환경변수에만 보관, 카드정보는 토스가 처리(우리 서버에 저장 안 함) |
| 운영 편의 | 교재·가격·회사정보 수정은 `shop/products.js` 한 파일만 수정 |
| 비용 | 호스팅 Vercel 무료 플랜, 결제 수수료만 발생 |

## 7. 시스템 구성

```
[학부모 휴대폰]
     │  shop/index.html (교재목록·장바구니·주문서)
     │  └ 토스 결제위젯 ─────────────▶ [토스페이먼츠]
     ▼                                       │ 결제 인증 완료
shop/success.html ── POST /api/confirm ─────▶│
                     (Vercel 서버 함수)       │ 승인 API
                         │  ◀────────────────┘
                         └──▶ [구글 시트] 주문 기록
```

| 파일 | 역할 |
|---|---|
| `shop/products.js` | **교재 목록·가격·배송비·회사정보·결제 키 (운영자가 수정)** |
| `shop/index.html`, `shop.js`, `shop.css`, `common.js` | 교재몰 화면 |
| `shop/success.html`, `shop/fail.html` | 결제 결과 화면 |
| `api/confirm.js` | 결제 승인 서버 (금액 검증 → 토스 승인 → 시트 기록) |
| `docs/google-sheet-order-script.gs` | 구글 시트 주문 기록용 스크립트 |

## 8. 운영 프로세스

1. 결제 완료 → 구글 시트 '주문' 탭에 한 줄 자동 추가 (처리상태: 접수)
2. 데스크가 매일 오전 시트를 **캠퍼스/반**으로 필터 → 교재 준비 → 상태를 '전달완료'로 변경
3. 택배 건은 송장 출력 후 '발송완료'
4. 환불: 토스페이먼츠 상점관리자에서 해당 주문 취소 → 시트 상태 '환불'

## 9. 오픈 일정 (제안)

| 주차 | 할 일 | 담당 |
|---|---|---|
| 1주 | 토스페이먼츠 가입·계약 신청, 통신판매업 신고 확인, 약관 문구 준비 | 대표/경영지원 |
| 1주 | 실제 교재 목록·가격·사진 입력, Vercel 배포, 테스트 결제 | 운영(가이드 참고) |
| 2~3주 | 토스 심사 (사이트에 사업자정보·약관·환불정책 필수) | 토스 |
| 3주 | 라이브 키 교체 → 직원 대상 실제 소액 결제·환불 테스트 → 학부모 공지 | 운영 |

## 10. 향후 개선 (v2 후보)
- 알림톡(카카오)으로 주문 확인 메시지 발송
- 반별 '필수 교재 세트' 원클릭 구매 링크 (예: `?set=bridge-a`)
- 재고 수량 관리, 관리자 화면
- 수강료 결제와 통합
