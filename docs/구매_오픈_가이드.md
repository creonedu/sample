# 실제 결제가 되도록 만드는 방법 (비개발자용 단계별 가이드)

> 지금 교재몰은 **테스트 모드**로 완성되어 있습니다.
> 화면·장바구니·결제창까지 모두 작동하지만 **실제 돈은 빠져나가지 않습니다.**
> 아래 순서대로 하시면 실제 결제를 받을 수 있습니다. 코딩은 필요 없습니다.

전체 흐름 한눈에 보기:

| 단계 | 하는 일 | 걸리는 시간 | 누가 |
|---|---|---|---|
| 1 | 통신판매업 신고 확인 | 하루~3일 | 대표/경영지원 |
| 2 | 사이트를 인터넷에 올리기 (Vercel) | 15분 | 누구나 |
| 3 | 교재·가격·회사정보 입력 | 30분 | 누구나 |
| 4 | 토스페이먼츠 가입·계약 신청 | 신청 30분 + 심사 1~2주 | 대표 |
| 5 | 주문이 구글 시트로 들어오게 연결 | 15분 | 누구나 |
| 6 | 약관·개인정보처리방침 교체 | 법률 검토 기간 | 대표/법무 |
| 7 | 실제 결제 키로 교체 | 10분 | 누구나 |
| 8 | 실제 소액 결제 → 환불 테스트 후 공지 | 30분 | 운영 |

---

## 1단계. 통신판매업 신고 확인 (필수)

온라인으로 물건(교재)을 팔려면 **통신판매업 신고**가 법적으로 필요하고, 결제사(토스) 심사에서도 확인합니다.

1. 이미 신고했다면 → **신고번호**를 메모해두세요. (예: 제2026-경기수원-0000호)
2. 아직이면 → **정부24 (gov.kr)** 에서 "통신판매업 신고" 검색 → 온라인 신청.
   - 준비물: 사업자등록증, (온라인 결제를 쓰므로) 토스페이먼츠의 **구매안전서비스 이용확인증**
   - 확인증은 4단계에서 토스 가입 후 발급받을 수 있으니, **4단계와 함께 진행**하시면 됩니다.
3. 사업자등록증의 업종에 **"전자상거래 소매업"** 이 없다면 홈택스에서 업종 추가를 함께 신청하세요. (세무사님께 요청하셔도 됩니다)

---

## 2단계. 사이트를 인터넷에 올리기 (Vercel, 무료)

결제 승인에는 작은 서버가 필요해서, 무료 호스팅인 **Vercel**을 씁니다. 코드는 이미 Vercel용으로 준비되어 있습니다.

1. **https://vercel.com** 접속 → **Sign Up** → **"Continue with GitHub"** 클릭 (지금 코드가 있는 GitHub 계정으로 로그인)
2. 화면의 **"Add New…" → "Project"** 클릭
3. 목록에서 **`creonedu/sample`** 저장소 옆 **Import** 클릭
   - 목록에 안 보이면 "Adjust GitHub App Permissions" 를 눌러 이 저장소 접근을 허용하세요.
4. 설정은 아무것도 바꾸지 말고 **Deploy** 클릭 → 1분 정도 기다리기
5. 완료되면 `https://sample-xxxx.vercel.app` 같은 주소가 나옵니다. 클릭하면 **교재몰이 열립니다.**
6. **테스트 결제 해보기**: 교재 담기 → 주문하기 → 정보 입력 → 카드 선택 → 결제하기
   - 테스트 모드라 아무 카드 정보나 넣어도 되고, 돈은 빠져나가지 않습니다.
   - "주문이 완료되었습니다" 화면이 나오면 성공입니다.

> 💡 이후 GitHub에서 파일을 고치면 Vercel이 **자동으로 1~2분 안에 사이트에 반영**합니다.

---

## 3단계. 실제 교재·가격·회사정보 입력

고칠 파일은 **`shop/products.js` 하나뿐**입니다.

1. GitHub에서 `creonedu/sample` 저장소 → `shop` 폴더 → `products.js` 클릭
2. 오른쪽 위 **연필(✏️) 아이콘** 클릭 → 내용 수정
3. 고칠 곳:
   - **company**: 대표자명, 사업자등록번호, 통신판매업 신고번호, 주소, 전화, 이메일, 개인정보보호책임자
   - **shipping**: 택배비, 무료배송 기준 금액
   - **products**: 교재 목록 (지금은 예시입니다)
     - 교재 1권 = `{ id: ..., name: ..., price: ... }` 한 줄
     - 추가: 한 줄 복사 → 붙여넣기 → `id`는 다른 영문으로, 이름·가격 수정
     - 품절: `soldOut: false` → `soldOut: true`
     - 가격은 숫자만: `18000` (쉼표·"원" 금지)
4. 아래 **"Commit changes"** 초록 버튼 클릭 → 다시 **Commit changes**
5. 2분 뒤 사이트 새로고침해서 확인

> ⚠️ **따옴표(')·쉼표(,)를 지우면 사이트가 깨집니다.** 깨지면 당황하지 마시고, GitHub의 "History"에서 이전 버전으로 되돌리거나 Claude에게 "products.js 고쳐줘"라고 요청하세요.

**교재 사진 넣기 (선택)**: `shop/images` 폴더에 사진 업로드(GitHub의 "Add file → Upload files") → products.js에서 `image: 'images/사진이름.jpg'` 로 적기. 사진이 없으면 레벨 색상 표지가 자동으로 나옵니다.

## 4단계. 토스페이먼츠 가입·계약 (실제 돈을 받기 위한 핵심 단계)

1. **https://www.tosspayments.com** → **"시작하기/가입하기"** → 사업자로 가입
2. **"전자결제 신청"** 진행. 보통 아래 서류를 요청합니다 (토스 화면 안내가 정답입니다):
   - 사업자등록증, 대표자 신분증, 정산받을 법인 통장 사본, 법인 인감증명서 등
3. 신청서의 **"사이트 주소"** 에 2단계에서 받은 Vercel 주소 입력
4. 원하는 결제수단 선택 (카드, 계좌이체, 가상계좌, 토스페이·카카오페이·네이버페이 등)
5. 심사 중 토스에서 **사이트에 사업자정보·약관·환불정책이 있는지** 확인합니다
   → 3단계(회사정보)와 6단계(약관)를 **심사 전에 끝내두면** 빠릅니다.
6. 가입 후 **구매안전서비스 이용확인증**을 발급받아 1단계 통신판매업 신고에 사용하세요.
7. 심사 승인되면 **개발자센터 → API 키** 메뉴에서 키를 확인할 수 있습니다. (7단계에서 사용)

> 수수료는 결제수단·계약 조건에 따라 다릅니다 (카드 기준 대략 2~3%대). 계약 시 확인하세요.

## 5단계. 주문이 구글 시트로 자동으로 들어오게 연결

토스 관리자 화면에도 결제 내역은 남지만, **학생 이름·반·배송지**는 구글 시트에서 보시는 게 편합니다.

1. 구글 드라이브에서 **새 구글 시트** 만들기 (이름 예: "교재몰 주문")
2. 메뉴 **확장 프로그램 → Apps Script** 클릭
3. 기존 내용을 모두 지우고, 이 저장소의 **`docs/google-sheet-order-script.gs`** 내용을 통째로 복사해 붙여넣기
4. 맨 위 `var SECRET = '...'` 의 따옴표 안을 **아무도 모르는 문자열**로 바꾸기 (예: `creon-2026-x8k2p`) → 메모해두기
5. 💾 저장 → 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
   - **배포** → 권한 승인(구글 계정 선택 → "고급" → "이동") → 나오는 **웹 앱 URL 복사**
6. **Vercel** → 내 프로젝트 → **Settings → Environment Variables** 에서 두 개 추가:

   | Key (이름) | Value (값) |
   |---|---|
   | `ORDER_WEBHOOK_URL` | 5번에서 복사한 웹 앱 URL |
   | `ORDER_WEBHOOK_SECRET` | 4번에서 정한 문자열 |

7. Vercel **Deployments** 탭 → 맨 위 항목의 **⋯ → Redeploy** (환경변수는 재배포해야 적용됩니다)
8. 테스트 결제를 한 번 더 해보고, 시트에 **'주문' 탭과 한 줄**이 생기면 성공!

> 시트의 마지막 칸 **처리상태**를 데스크에서 '전달완료/발송완료/환불'로 바꿔가며 관리하시면 됩니다.

## 6단계. 약관·개인정보처리방침·환불정책 교체

사이트 하단과 결제 화면에 있는 약관은 **예시 문구**입니다.

1. 법무 담당 또는 노무/법률 자문을 통해 문구를 준비하세요.
   - 개인정보처리방침은 **개인정보보호위원회 "개인정보 처리방침 만들기"** (privacy.go.kr) 에서 무료로 작성할 수 있습니다.
2. 완성된 문구를 Claude에게 주시고 "약관 바꿔줘"라고 하시면 됩니다. (파일: `shop/common.js`)

## 7단계. 실제 결제 키로 교체 (테스트 → 실결제 전환)

토스 심사가 **승인된 후**에 합니다.

1. 토스페이먼츠 **개발자센터 → API 키** → **"결제위젯 연동 키"** 의 **라이브** 키 2개 확인
   - ⚠️ "API 개별 연동 키"가 아니라 **"결제위젯 연동 키"** 여야 합니다.
   - **클라이언트 키**: `live_gck_` 로 시작 (공개돼도 되는 키)
   - **시크릿 키**: `live_gsk_` 로 시작 (**절대 남에게 보여주거나 GitHub에 올리면 안 되는 키**)
2. **클라이언트 키** → GitHub의 `shop/products.js` 에서 `tossClientKey: '...'` 따옴표 안을 교체 → Commit
3. **시크릿 키** → Vercel → Settings → Environment Variables 에 추가:

   | Key | Value |
   |---|---|
   | `TOSS_SECRET_KEY` | `live_gsk_...` |

4. Vercel에서 **Redeploy**
5. 사이트 상단의 노란 "테스트 모드" 띠가 **사라졌는지** 확인

> 🔐 시크릿 키가 유출됐다고 의심되면 즉시 토스 개발자센터에서 키를 재발급하고 3번을 다시 하세요.

## 8단계. 실제 소액 결제 테스트 → 오픈

1. products.js에 **1,000원짜리 테스트 교재**를 하나 임시로 추가 (`id: 'test-1000'`)
2. 대표님 카드로 **실제 결제** → 완료 화면, 문자/영수증, 구글 시트 기록 확인
3. 토스페이먼츠 **상점관리자 → 거래내역** 에서 해당 결제를 **취소(환불)** → 환불 문자 확인
4. 테스트 교재 삭제 → Commit
5. **학부모 공지**: Vercel 주소(또는 아래 도메인)를 알림장/문자/카카오 채널로 안내 🎉

---

## (선택) 우리 회사 주소로 바꾸기 — 예: shop.creonedu.co.kr

1. Vercel → 프로젝트 → **Settings → Domains** → `shop.회사도메인` 입력 → Add
2. Vercel이 알려주는 **CNAME 값**을 도메인 구입처(가비아, 후이즈 등)의 DNS 설정에 추가
3. 10분~몇 시간 뒤 연결 완료 (보안 인증서 자동 적용)
4. 토스페이먼츠에 등록한 사이트 주소도 새 주소로 변경 요청

| 교재 추가·가격 변경·품절 처리 | GitHub `shop/products.js` |

## 자주 묻는 질문

- **Q. 비용이 드나요?** Vercel·GitHub·구글 시트는 무료. 결제 건마다 토스 수수료만 발생합니다.
- **Q. 카드번호가 우리 서버에 저장되나요?** 아니요. 카드 정보는 토스가 처리하고, 우리 쪽에는 주문 정보만 남습니다.
- **Q. 누가 화면에서 가격을 조작하면요?** 서버가 `products.js` 가격표로 다시 계산해서 금액이 다르면 결제를 승인하지 않습니다.
- **Q. 막히면?** 이 화면의 Claude에게 "N단계에서 막혔어, 화면에 OO라고 떠" 라고 알려주세요.
